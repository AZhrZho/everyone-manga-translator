# Bundled font notice

EMT Studio bundles **ZCOOL KuaiLe Regular** as its redistributable default
Simplified Chinese font.

- Project: ZCOOL KuaiLe
- Upstream: https://github.com/google/fonts/tree/main/ofl/zcoolkuaile
- Copyright: Copyright 2018 The ZCOOL KuaiLe Project Authors
- License: SIL Open Font License 1.1

The complete license text is stored at
`fonts/F0002/LICENSE.txt`. The font file remains under the SIL Open Font
License and is not relicensed by EMT Studio.

Microsoft YouYuan (`SIMYOU.TTF`) is not bundled. On Windows, EMT Studio may
copy it from the user's existing Windows Fonts installation into that user's
application data directory. If the font is not installed, startup continues
with ZCOOL KuaiLe only.
